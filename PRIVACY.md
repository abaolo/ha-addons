# Tietosuojaseloste / Privacy policy

Tämä on yksityinen, kotikäyttöön tarkoitettu Home Assistant -asennus. Google-tilin tietoja
(esim. kalenteritapahtumia) käytetään vain omassa Home Assistant -palvelimessa käyttäjän omiin
tarkoituksiin. Tietoja ei myydä, jaeta kolmansille osapuolille eikä käytetä mainontaan.
Käyttöoikeuden voi perua milloin tahansa osoitteessa https://myaccount.google.com/permissions.

This is a private Home Assistant installation for personal home use. Google account data
(such as calendar events) is used only on the owner's own Home Assistant server for the
owner's own purposes. Data is not sold, shared with third parties or used for advertising.
Access can be revoked at any time at https://myaccount.google.com/permissions.
